# date-after UX改善ループ

date-afterを10回、異なる観点でレビューした記録。各回は「観察 → 判断 → 修正 → 再確認」で実施した。

1. 日数がselectのみになる危険 → 任意値をnumber inputへ変更 → 37など任意値で計算。
2. 今日を毎回入力する負荷 → 今日を初期値＋今日ボタン → 開いた直後に結果を表示。
3. 前後を別ページで探す負荷 → 方向を同一画面のbutton groupへ → 1タップで切替。
4. 日だけでは用途が限定される → 日・週・月・年をbutton groupへ → 単位を1タップで変更。
5. 頻出日数の手入力 → 1・7・14・30・100のpreset → 1タップ入力。
6. 結果の数字だけでは意味が弱い → 日付＋曜日＋計算内容 → 結論を先頭表示。
7. 結果の再利用 → 結果コピーを追加 → 1タップでコピー。
8. 初期状態の戻し方がない → リセットを追加 → 今日・30日・日・加算へ復帰。
9. 月末計算の曖昧さ → 月・年の暦移動と月末クランプを実装 → うるう年・月末を確認。
10. キーボードとスマホ → label、inputmode、44px操作領域、aria-pressedを確認 → Tab、入力、ボタン操作を再確認。

同じ問題の言い換えではなく、入力方式、初期値、操作構造、結果、再利用、境界条件、アクセシビリティを別々に確認した。
