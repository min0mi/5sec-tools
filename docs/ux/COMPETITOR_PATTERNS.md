# Competitor UX Patterns

date-afterのパイロット調査。固有の文章・配色・コードは採用せず、操作パターンだけを比較した。

| 参考サイト | 入力・preset | 結果・補助機能 | 採用判断 |
| --- | --- | --- | --- |
| Day Calculator | 日付、方向、任意量、日/週/月/年 | 日付、曜日、今日からの距離 | 単位と曜日を採用。計算ボタンは省略 |
| DateSpan | 今日初期値、方向、年/月/週/日 | 即時計算、ISO日付、曜日、移動日数 | 入力の自由度と即時更新を採用 |
| Spinumbers | 日付、加算/減算、日/週/月/年、今日 | 曜日、営業日への発展 | 方向切替と今日ボタンを採用 |
| Calcowa | 加算/減算のモード、複数単位 | 結果日、曜日、現在からの距離 | 結論を大きく表示する考え方を採用 |
| JustCalcs | 日・営業日・週・月・年 | 日付、曜日、単位の説明 | 将来の営業日拡張候補。今回は過剰機能にしない |
| Keisan | 基準日＋日数、関連計算への導線 | 日付計算と関連機能 | 入力項目を少なくする考え方を採用 |

## 統合した5sec仕様

基準日は今日、量は number input、頻出値は1・7・14・30・100のチップ、方向と単位はbutton group、結果は日付＋曜日＋計算内容、コピーとリセットを結果付近に置く。日付を直接入力できないselect構成、長い説明、必須の計算ボタンは採用しない。
