# 5sec-tools UX Rules

## 目的

「開く → 入力 → 答え」を5秒以内に近づける。見た目の装飾より、入力回数・クリック数・迷い・結果理解の摩擦を減らす。

## 入力方式

- 任意の数値・金額は number input。selectだけで閉じない。
- 日付は date input、時刻は time input、長文は textarea、ファイルは file picker / drag & drop。
- 2〜5個の固定選択肢は segmented control または button group。多数の固定選択肢だけselectにする。
- 頻出値がある数値は、自由入力を残したまま preset chips を添える。
- 単位は入力の直後に表示し、単位選択が必要な場合だけ最小限の選択肢を置く。

## 結果と操作

- リアルタイム計算できるものに計算ボタンを置かない。
- ユーザーの結論を最初に大きく表示し、単位・内訳・比較対象を同時に読めるようにする。
- コピーは再利用される結果だけに置く。リセットは入力が複数ある場合に置く。
- エラーは「何をどう直すか」を具体的に書き、入力途中に過剰表示しない。

## モバイルとキーボード

- 本文と入力文字は16px以上、主要操作は44px以上。
- number inputには適切なinputmodeを付ける。hoverだけに依存しない。
- label、focus表示、Tab移動、Enter操作を維持する。
- 主要入力と結果をファーストビューに置く。

## レビュー

初見、急いでいる人、スマートフォン片手操作、キーボード操作、初心者の5視点で「この操作は本当に必要か」を確認する。個別ツールのボタン名ではなく、再利用可能なルールとして更新する。
