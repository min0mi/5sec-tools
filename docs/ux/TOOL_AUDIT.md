# Tool UX Audit

| ID | ツール | 入力方式 | 結果 | 主な補助 |
| --- | --- | --- | --- | --- |
| T01 | 日付＋日数 | date + number + preset + segmented | 日付・曜日・計算内容 | 今日、コピー、リセット |
| T02 | 日付ー日数 | date + number + preset | 日付・曜日 | コピー |
| T03 | 日付の差 | date × 2 | 日数・前後 | 今日、コピー |
| T04 | 動画倍速 | number × 2 + preset | 再生時間 | リアルタイム |
| T05 | 割引計算 | 金額number + 割合number + preset | 支払額・値引き額 | リアルタイム、コピー |
| T06 | パーセント | number + 割合number + preset | 該当数値・式 | リアルタイム、コピー |
| T07 | 単価比較 | 金額number × 2組 | お得な商品・単価 | リアルタイム、コピー |
| T08 | 時給から月収 | number × 3 + preset | 月収・週収・年収 | リアルタイム |
| T09 | 文字数 | textarea | 文字数・除外数・行数等 | サンプル、クリア、コピー |
| T10 | ランダム抽選 | textarea | 選択結果 | サンプル、クリア、抽選 |
| T11 | 画像形式変換 | file picker / drag & drop | プレビュー・保存 | 複数、品質、形式 |
| T12 | 画像トリミング | file + canvas crop | プレビュー・保存 | ハンドル、比率、数値 |

全ツール共通で、任意値をselectだけにせず、入力途中でも結果を更新し、スマートフォンのタップ領域とfocus表示を確保する。
